03 / Defensive checklist

Signals worth checking.

These indicators are useful clues, not a guarantee that a URL is malicious or safe.

CHECK / 01

Destination mismatch

Inspect the actual destination. A familiar brand name in visible text does not prove the destination is legitimate.

CHECK / 02

Unexpected redirects

Unexpected domain changes, URL shorteners, and unrelated destinations deserve extra scrutiny.

CHECK / 03

Unexpected downloads

Do not run unsolicited files. Verify the source and signature; use reputable endpoint protection and a managed sandbox.
